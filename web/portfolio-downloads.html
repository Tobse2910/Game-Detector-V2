Meine Anwendungen

Zwei Programme für Windows, entstanden aus eigenen Problemen. Beide sind kostenlos, laufen ohne Konto und ohne Cloud auf deinem Rechner, und der Quellcode liegt offen.

OBS Game Detector

Für Twitch-Streamer. Das Plugin wertet aus, welches Fenster bei dir gerade vorne ist, und setzt danach Kategorie und Streamtitel automatisch. Spiel vorne heißt Kategorie ist das Spiel, Browser heißt Just Chatting, Discord und OBS ändern gar nichts. Gewechselt wird erst, wenn das eine Weile stabil so bleibt. Neue Versionen meldet es selbst und installiert sie auf einen Klick.

Läuft auf: Windows OBS 28+

1.3.6

Call Klingel

Eingehende Handy-Anrufe am PC sehen und annehmen. Über Bluetooth wird der Rechner zur Freisprechanlage, ohne Cloud, ohne zweite Rufnummer und ohne App auf dem Handy. Das Telefon bleibt das Telefon, der PC spricht nur das Freisprechprofil mit ihm. Kontakte werden lokal gelesen, Rufnummern in Protokollen maskiert.

Läuft auf: Windows Bluetooth

Installer für Windows Portable Fassung Quellcode

Windows warnt bei Programmen ohne kostenpflichtige Signatur. Beim Game Detector liegt ein Installationsskript bei, das den Einbau übernimmt und vorher prüft, ob OBS noch läuft. Call Klingel bringt einen eigenen Installer mit.

Steht beim Game Detector unten in den Einstellungen keine Versionsnummer, ist eine sehr frühe Fassung installiert, die noch keine Update-Prüfung hatte. Die meldet sich nie von selbst. Einmal hier herunterladen und installieren, danach kommen die Hinweise automatisch.

Beide Programme entstehen in der Freizeit. Wer einen Fehler findet oder etwas vermisst, kann auf GitHub ein Thema eröffnen oder mich direkt anschreiben.
