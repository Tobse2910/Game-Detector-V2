Game Detector V2 für OBS

Smart Context Mode

Erkennt, welche Anwendung du gerade tatsächlich benutzt, und setzt danach automatisch deine Twitch-Kategorie und deinen Streamtitel. Nicht "läuft irgendwo ein Spiel", sondern "welches Fenster ist vorne", und der Wechsel passiert erst, wenn das eine Weile stabil so bleibt. Neue Versionen meldet das Plugin selbst und installiert sie auf einen Klick.

Call Klingel

Erste Fassung

Eingehende Handy-Anrufe am PC sehen und annehmen. Über Bluetooth wird der Rechner zur Freisprechanlage, ohne Cloud, ohne zweite Rufnummer und ohne App auf dem Handy. Windows läuft; Linux und macOS starten, können aber noch nicht telefonieren.

Windows warnt bei Programmen ohne kostenpflichtige Signatur. Beim Game Detector liegt deshalb ein Installationsskript bei, das den Einbau übernimmt und vorher prüft, ob OBS noch läuft.

Steht beim Game Detector unten in den Einstellungen keine Versionsnummer, ist eine sehr frühe Fassung installiert, die noch keine Update-Prüfung hatte. Die meldet sich nie von selbst. Einmal hier herunterladen und installieren, danach kommen die Hinweise automatisch.

Beide Programme entstehen in der Freizeit und sind kostenlos. Wer einen Fehler findet oder etwas vermisst, kann auf GitHub ein Thema eröffnen oder sich direkt melden.
