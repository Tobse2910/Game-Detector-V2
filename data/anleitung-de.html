Game Detector V2

Smart Context Mode. Das Plugin setzt deine Twitch-Kategorie und deinen Streamtitel, je nachdem womit du gerade arbeitest.

Was es macht

Das Plugin schaut jede Sekunde nach, welches Fenster bei dir vorne ist. Nicht ob irgendwo ein Spiel im Hintergrund läuft, sondern welches Programm du gerade benutzt. Bleibt dasselbe Programm eine Weile vorne, setzt das Plugin die passende Kategorie und den Titel auf Twitch.

Die Wartezeit ist Absicht. Wer während einer Runde kurz in den Browser wechselt, will nicht, dass die Kategorie mitspringt.

Einmal einrichten

1. Twitch verbinden

In diesem Fenster unter Verbindungen auf Twitch: Verbinden. Der Browser geht auf, du bestätigst den Zugriff, fertig. Lass Gemeinsame Berechtigungen angehakt, sonst fehlt dem Plugin das Recht, Kategorie und Titel zu ändern.

2. Plattform-Aktion prüfen

Rechts muss Kategorie über API stehen. Die andere Einstellung schickt nur einen Chat-Befehl an einen Bot und verwirft deinen Titel.

3. Smart Context Mode anschalten

Im Dock, nicht hier. Den Haken bei Smart Context Mode setzen und eine Verzögerung wählen. Voreingestellt sind 5 Minuten.

Regeln

Eine Regel sagt: dieses Programm bedeutet diese Kategorie. Zu finden unter Smart-Context-Regeln verwalten. Eine Regel hat sechs Felder.

  • Programm: der Dateiname, zum Beispiel FiveM_*.exe. Ein * steht für beliebig viele Zeichen, ein ? für eines. Das hilft bei Spielen, deren Dateiname die Version enthält.
  • Fenstertitel: leer lassen, außer du willst ein Programm nach Titel unterscheiden.
  • Kategorie: der Name, wie er bei Twitch heißt. Tippfehler lehnt Twitch ab.
  • Titelvorlage: leer heißt, der Titel bleibt unberührt. Sonst siehe Platzhalter weiter unten.
  • Verzögerung: eigene Zeit für diese Regel, oder Standard.
  • Priorität: passen mehrere Regeln, gewinnt die höchste. Bei Gleichstand schlägt ein genauer Dateiname einen mit Platzhaltern.

Spiele aus deinen Steam-, Epic-, GOG- und Ubisoft-Bibliotheken erkennt das Plugin auch ohne Regel. Eine Regel mit genauem Dateinamen gewinnt trotzdem, weil du sie ausdrücklich angelegt hast.

Ignorierte Programme

Programme auf dieser Liste ändern die Kategorie nie. Discord, Spotify, OBS selbst, der Stream Deck, die Spiele-Launcher. Sie halten auch den Timer nicht auf: wer mitten in einer Runde zwei Minuten in Discord redet und zurückkommt, verliert die angesammelte Zeit nicht.

Zu finden im Dock unter Programme ignorieren. Eine Zeile anklicken, Entfernen, dann mit OK schließen. Ohne OK wird nichts gespeichert.

Der leere Schreibtisch gehört zwar zu explorer.exe, zählt aber nicht als Programm. Er läuft an den Regeln vorbei, damit die feste Kategorie greifen kann. Ein Explorer-Fenster mit Ordnern bleibt ein Programm wie jedes andere.

Feste Kategorie, wenn nichts erkannt wird

Im Dock, unter der Verzögerung. Haken setzen, Kategorie eintragen, zum Beispiel Just Chatting oder IRL. Ab dann setzt das Plugin diese Kategorie, sobald du bei etwas bist, für das keine Regel existiert.

Das ist die letzte Stufe. Eine Regel gewinnt immer. Sitzt du in Visual Studio Code und hast dafür eine Regel, kommt deren Kategorie und nicht die feste. Wenn du das nicht willst, ändere oder lösche diese Regel.

Der Titel fällt dabei auf deinen eigenen zurück. Wer FiveM verlässt, hat den Servernamen nicht weiter im Titel stehen.

FiveM: der Server im Titel

Bei FiveM ist die Kategorie immer Grand Theft Auto V, egal auf welchem Server du spielst. Interessant ist der Server, und den erkennt das Plugin selbst.

Trage in deiner FiveM-Regel als Titelvorlage ein:

{server} | dein Text

Daraus wird zum Beispiel Mein Server | Mein Text | !befehle. Wechselst du im laufenden FiveM den Server, tauscht das Plugin nur den Teil vorne. Kennt es den Server nicht, fällt er samt Trennzeichen weg und dein Text bleibt allein stehen.

Woran es den Server erkennt

Zwei Quellen zusammen. Das FiveM-Log nennt bei jedem Verbinden die Ressourcen, die der Server angefordert hat. Die Angaben, die FiveM zu Servern speichert, enthalten dieselbe Liste und den Namen. Stimmen beide Listen überein, ist der Name der richtige. Passt nichts, bleibt der Name weg. Ein falscher Name im Titel wäre schlimmer als keiner.

Für einen Server, dessen Angaben FiveM noch nicht gespeichert hat, gibt es keinen Namen. Öffne ihn einmal in der FiveM-Serverliste, dann legt FiveM die Angaben an.

Platzhalter im Titel

PlatzhalterWird ersetzt durch
{titel}Deinen eigenen Titel, also den Teil, der nicht vom Plugin kommt. Schreibst du den Titel selbst um, gilt ab dann deiner.
{server}Den FiveM-Servernamen.
{game}Die Kategorie, die gerade gesetzt wird.
{app}Den Programmnamen ohne .exe.
{window}Den Fenstertitel des Programms.

{server} und {titel} nehmen ihr Trennzeichen mit, wenn sie leer sind. Aus {server} | Mein Text wird also Mein Text und nicht | Mein Text.

Streaminformation im Dock

Unten im Dock setzt du Titel, Kategorie, Tags, Sprache, Inhaltskennzeichnung und gesponserte Inhalte. Alles direkt über die Twitch-Schnittstelle.

  • Titel: bis 140 Zeichen, der Zähler läuft mit.
  • Tags: bis zehn, je bis 25 Zeichen, nur Buchstaben und Zahlen.
  • Die Kennzeichnung Mature-rated game setzt Twitch selbst anhand der Kategorie. Sie steht grau da und lässt sich nicht von Hand ändern.

Das OBS-Fenster Streaminformation brauchst du nicht mehr. Es ist ein Eingabeformular, kein Spiegel deines Kanals. Nach einem Wechsel über die Schnittstelle zeigt es weiter den alten Wert, und sein Fertig-Knopf schreibt diesen alten Wert zurück auf Twitch. Was wirklich auf deinem Kanal steht, siehst du hier im Dock.

Manuelle Steuerung

  • Übernehmen: setzt die gewählte Kategorie sofort, mit der Titelvorlage, die dazu gehört.
  • Jetzt wechseln: führt den anstehenden Wechsel sofort aus, ohne den Rest der Wartezeit.
  • Timer zurücksetzen: verwirft den anstehenden Wechsel.
  • Kategorie sperren: das Plugin ändert nichts mehr, bis du den Haken wieder entfernst. Gut für einen Sonderstream.

Updates

Das Plugin prüft bei jedem OBS-Start, ob es etwas Neues gibt, und während OBS läuft alle sechs Stunden noch einmal. Gibt es eine neuere Fassung, steht oben im Dock ein Hinweis.

Ein Klick darauf lädt sie, fragt einmal nach Administratorrechten, beendet OBS, tauscht das Plugin aus und startet OBS wieder. Geht beim Austauschen etwas schief, kommt die vorherige Fassung zurück. Deine Einstellungen bleiben.

Während du live bist oder aufnimmst, verweigert das Plugin das Update. Es müsste OBS beenden.
