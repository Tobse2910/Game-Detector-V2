Game Detector V2

Smart Context Mode. The plugin sets your Twitch category and stream title based on what you are actually working in.

What it does

Once a second the plugin checks which window is in front. Not whether a game runs somewhere in the background, but which program you are using. Once the same program stays in front for a while, the plugin sets the matching category and the title on Twitch.

The waiting time is deliberate. Nobody wants the category to jump because they checked the browser mid-round.

Set up once

1. Connect Twitch

In this window under Connections, click Twitch: Connect. The browser opens, you confirm access, done. Leave Shared permissions ticked, otherwise the plugin lacks the right to change category and title.

2. Check the platform action

On the right it has to say Category via API. The other setting only sends a chat command to a bot and discards your title.

3. Turn on Smart Context Mode

In the dock, not here. Tick Smart Context Mode and pick a delay. The default is 5 minutes.

Rules

A rule says: this program means this category. Under Manage Smart Context rules. A rule has six fields.

  • Process: the file name, for example FiveM_*.exe. A * stands for any number of characters, a ? for one. Useful for games whose file name carries the version.
  • Window title: leave empty unless you want to tell one program apart by title.
  • Category: the name as Twitch spells it. Twitch rejects typos.
  • Title template: empty leaves your title alone. Otherwise see the placeholders below.
  • Delay: an own time for this rule, or the default.
  • Priority: when several rules match, the highest wins. On a tie an exact file name beats one with wildcards.

Games from your Steam, Epic, GOG and Ubisoft libraries are recognised without a rule. A rule with an exact file name still wins, because you wrote it on purpose.

Ignored applications

Programs on this list never change the category. Discord, Spotify, OBS itself, the Stream Deck, the game launchers. They also do not age the timer: talking in Discord for two minutes mid-round and coming back does not cost the time you collected.

In the dock under Ignored applications. Click a row, Remove, then close with OK. Without OK nothing is saved.

The empty desktop belongs to explorer.exe but does not count as a program. It bypasses the rules so the fixed category can apply. An Explorer window with folders stays a program like any other.

Fixed category when nothing is recognised

In the dock, below the delay. Tick it, enter a category, for example Just Chatting or IRL. From then on the plugin sets this category whenever you are in something no rule covers.

This is the last resort. A rule always wins. Sitting in Visual Studio Code with a rule for it gets you that rule's category, not the fixed one. Change or delete the rule if you want it otherwise.

The title falls back to your own. Leaving FiveM drops the server name from it.

FiveM: the server in the title

With FiveM the category is always Grand Theft Auto V, whatever server you play on. The server is the interesting part, and the plugin works it out itself.

Put this in your FiveM rule as the title template:

{server} | your text

That turns into My Server | My text | !commands. Switch servers inside a running FiveM and the plugin swaps only the part in front. When it does not know the server, that part drops out with its separator and your text stands alone.

How it recognises the server

Two sources together. The FiveM log names the resources the server requested on every connect. The server details FiveM stores carry the same list plus the name. When both lists agree, the name is the right one. When nothing matches, no name is used. A wrong name in the title would be worse than none.

A server whose details FiveM has not stored yet yields no name. Open it once in the FiveM server list and FiveM stores them.

Title placeholders

PlaceholderReplaced by
{title}Your own title, the part that does not come from the plugin. Rewrite the title yourself and yours counts from then on.
{server}The FiveM server name.
{game}The category being set.
{app}The program name without .exe.
{window}The window title of the program.

{server} and {title} take their separator with them when empty. So {server} | My text becomes My text and not | My text.

Stream information in the dock

At the bottom of the dock you set title, category, tags, language, content classification and branded content. All through the Twitch interface.

  • Title: up to 140 characters, with a live counter.
  • Tags: up to ten, each up to 25 characters, letters and digits only.
  • Twitch sets the Mature-rated game label itself based on the category. It shows greyed out and cannot be changed by hand.

You no longer need OBS' own Stream Information window. It is an input form, not a mirror of your channel. After a change through the interface it still shows the old value, and its Done button writes that old value back to Twitch. What your channel really says is here in the dock.

Manual control

  • Apply: sets the chosen category right away, with its title template.
  • Switch now: carries out the pending switch without the rest of the wait.
  • Reset timer: drops the pending switch.
  • Lock category: the plugin changes nothing until you untick it. Handy for a special stream.

Updates

The plugin checks for a newer version on every OBS start, and every six hours while OBS runs. When there is one, a notice sits at the top of the dock.

One click downloads it, asks once for administrator rights, closes OBS, swaps the plugin and starts OBS again. If the swap goes wrong, the previous version comes back. Your settings stay.

While you are live or recording the plugin refuses to update. It would have to close OBS.

When something does not work

What you seeWhat causes it
The category does not change although the time is up Is Lock category ticked? Or does Detected context say Ignored, which means the program is on the ignore list.
The fixed category never applies A rule matched. Detected context tells you which category won. The fixed one is the last resort.
The server name is missing with FiveM Is {server} in your FiveM rule's title template? And does FiveM know the server yet? If not, open it once in the server list.
Twitch rejects the change The category name has to match Twitch exactly. And the platform action has to be Category via API.
The title is set but the category is not The permission is missing. Disconnect Twitch and connect again with Shared permissions.
The update check fails Usually the connection. The reason sits in the OBS log as cURL error. Try again later.
The version number is missing at the bottom of this window Then a very early build without update checking is running. It never reports for itself. Download once by hand.

Everything the plugin does lands in the OBS log. Every change is logged with its outcome, and with FiveM the recognised server as well.
